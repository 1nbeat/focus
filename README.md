# Focus

https://www.arifun.com

如你所见，就是一个简单的计时器。

## 特性

- 🌱 蒲公英随着专注时间生长
- ⏱️ 简洁的计时显示
- 🎯 轻量，无多余依赖

## 项目结构

```
focus/
├── src/
│   ├── App.vue      # 主组件（计时器逻辑）
│   ├── main.js      # 入口文件
│   └── style.css    # 全局样式
├── public/
│   └── icon.svg     # 图标
└── index.html       # HTML 模板
```

## 运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
